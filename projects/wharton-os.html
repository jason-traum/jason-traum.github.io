    Built with
    Claude Code agents, skills and hooks; Obsidian; Gmail, Google Calendar, Google Drive and Canvas; small Python scripts

    Wharton has a course site per class, two calendars and a lot of club email. In September I set up Claude Code to keep track of all of it. In October it grew into an Obsidian vault for everything I learn. By late October it had 94 class meetings, 114 readings and 276 concept notes.

    I borrowed the vault's structure from other people's setups and added my own checks, because if it misses one deadline I can't rely on it.

    Agents
    Inbox, calendar, classes, career and research, each reading one thing and reporting back
    Class skills
    Pull Canvas, digest a class meeting, rebuild a study guide, plan an exam, prep a case or a negotiation
    Life skills
    Sweep Gmail, prep a coffee chat, check a trip against everything else, a Sunday review, drafts in my voice

    How I learn with it

    Ideas across classes

    Each idea, like willingness to pay, switching costs or scaling laws, gets one concept note that links every lecture, reading and case that uses it, in any class. That's how I notice that marketing and operations are talking about the same idea.

    Folders only say what type of file something is. The class, session and exam go in each note's properties, so one reading can belong to all three at once.

    Two transcripts per class

    After class I pull the transcript from the class recording. The raw one is never edited and stays as the safety copy. The clean one is corrected against that day's slides, my handwritten notes, the readings and Canvas, with a mark on anything it isn't sure about.

    Each class meeting gets one note that links its transcripts, slides and readings.

    Study guides with my rules

    Claude rebuilds the study guide for each course by topic, from the class transcripts, my notes, the slides and the readings, using rules I wrote: every term gets a plain-English why and a takeaway.

    Why I can trust it

    Checking deadlines

    Before it writes any plan or answers "what's due", a script pulls every Canvas item from my calendar feed and lists anything that isn't on my task list. I added it after two deadlines got left off a weekend plan. Each plan starts with the result in one line.

    Canvas check: 13 items in the next 21 days, 0 missing.

    One ledger per course

    When I pulled everything from Canvas at the start of the semester, each course kept things somewhere different. One posted paper directions only in announcements, and another sent readings by email. So each course has its own ledger of what's due, and one task list pulls from all of them.

    Every date has a source

    Each deadline carries a pointer to where it came from, like a Canvas assignment, a syllabus page, an email or a calendar event. No date gets copied from memory or an old conversation, and today's date comes from the clock. If an agent's report and the task list disagree, it checks the source again and goes with the source.

    Who can change things

    Only my main Claude chat writes to my calendar and sorts my task list, and other AIs can add notes. I set that up after I had Claude go through two weeks of email and it added events to my calendar before I'd said yes. A hook blocks sending, deleting, trashing or sharing anything until I say yes in the chat, and a second hook logs every action.
